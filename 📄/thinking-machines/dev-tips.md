# Development Tips

## AI-assisted development

This documentation is mirrored in the `docs` folder of Tinker Cookbook. Consult the `AGENTS.md` or `CLAUDE.md` file in the Tinker Cookbook repository root for guidance about the codebase and documentation structure.

For developers using language models, two reference files are available:
- `llms.txt` -- a single-file version of the documentation
- `llms-full.txt` -- an extended version of the documentation

Clone the Tinker Cookbook repository and direct coding agents to the repository root for comprehensive context during development work.
