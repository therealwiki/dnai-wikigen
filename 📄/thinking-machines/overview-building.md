# Tinker Cookbook -- Overview

Three primary approaches for using Tinker:

1. **Dataset and Environment Integration** -- Define custom datasets and environments while leveraging existing training code from the cookbook.
2. **Custom Training Loop Development** -- Build training loops independently, beginning from fundamental concepts.
3. **Conceptual Understanding and Extension** -- Understand Tinker's classes and concepts to develop additional functionality.

## Recommended Starting Points

- **Rendering to Tokens** -- Explains the conversion process from conversation structures to token lists (chat templates)
- **LoRA Primer** -- Provides background on LoRA technology and guidance for hyperparameter selection. LoRA will give results that are roughly the same as full fine-tuning, however, you need to use different learning rates.
